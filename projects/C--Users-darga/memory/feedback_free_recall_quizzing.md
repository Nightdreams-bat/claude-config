For comprehensive review or revision sessions (e.g. `/tutor`, or checking retention across a whole vault area), the user prefers **free-recall questions** — asked in plain text, they write the answer in their own words, then it gets graded — rather than multiple-choice via AskUserQuestion. They said MCQ lets them recognize rather than retrieve, and they want to test whether they can actually relay the idea.

**Why:** free recall is a stronger test of genuine understanding and surfaces blind spots MCQ hides.

**How to apply:** during teaching (Phase 3 quiz-checks mid-lesson), MCQ via AskUserQuestion is still fine and fast. But for dedicated review/diagnostic passes, default to open questions in chat and grade them. Still update the concept tracker + dashboard the same way.
